Stepper

tokens/components/stepper.tokens.json · generated — the step indicator for a short (2–4 step) flow, and the Wizard around it. Recipe and behaviour in tools/lib/stepper.mjs.

Statesinactive = gray disc · active = fill.primary disc + number · complete = the same fill, the number becomes a check. The connector into a reached step fills blue.
Going backCompleted steps are buttons back to that step (hover: the disc darkens, the label turns link blue). Upcoming steps never are. Turn it off when a step can't be undone (after a payment).
PhoneBelow 768px: "Step 2 of 3 · Time" over a Progress sm bar — the full row doesn't fit.
Wizard footerRight-aligned, Secondary then Primary. First step: Cancel (nowhere to go back to). Middle steps: Back + Next. Last step: the action's own name — "Book appointment", "Send" — never "Submit" or "Finish".
ValidationNext is never disabled (a gray button doesn't say why). It checks the step's Fields like Form does — messages under the fields, focus on the first — and only then moves on. The last step checks every step and opens the first one that isn't right.
A11yAn ordered list with aria-current="step"; completed steps say so; each step's title takes focus when it opens, so a screen reader announces where you are.
