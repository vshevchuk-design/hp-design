TimePicker

tokens/components/time-picker.tokens.json · generated — a time-of-day field: the same trigger as DatePicker, opening a list of fixed slots. Joined to a DatePicker it makes the date + time field.

FieldDatePicker's trigger recipe, resolved from its token file — surface.dim, hairline border → border.strong hover → border.focus, 40px, 14px value — so a date and a time sit flush. Clock icon, the time (or a muted “Select time”), a clear × once there's a value, a chevron. The whole box opens the list.
ListListbox's panel and single-select rows (trailing fill.primary check, no row tint), rows declared at 36px. Every 30 minutes by default; step, min, max narrow it. The timezone suffix is text.muted. Opens scrolled to the selected slot, or to 9 AM.
Pick-onlyNo free typing: half-hours are faster to scan than a typed time is to validate. Keyboard: ↑ / ↓, Home / End, Enter picks, Escape closes.

<div class="timepicker" id="start-time" data-value="09:30">
  <div class="timepicker__control">
    <button class="timepicker__trigger" type="button" popovertarget="start-time-panel" aria-haspopup="listbox" aria-label="Start time">
      …schedule…<span class="timepicker__value">09:30 AM <span class="timepicker__zone">EST</span></span>
    </button>
    <button class="timepicker__clear" type="button" aria-label="Clear start time">…close…</button>
    …expand_more (class="timepicker__chevron")…
  </div>
  <div class="timepicker__panel" id="start-time-panel" popover>
    <ul class="timepicker__list" role="listbox" aria-label="Start time">
      <li class="timepicker__option" role="option" data-value="09:30" aria-selected="true" tabindex="-1">
        <span>09:30 AM <span class="timepicker__zone">EST</span></span>…check (class="timepicker__check")…
      </li>
      …one per slot…
    </ul>
  </div>
</div>
<!-- on pick / clear the .timepicker fires a bubbling "timechange" event, detail.value = "09:30" or "" -->
