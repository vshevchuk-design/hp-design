Message

tokens/components/message.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, nothing hand-copied. Colors are CSS custom properties, not literal hex.

The rich content typeHeadings-as-bold-labels, mixed text, bulleted links, images, one or more file Attachments, one CTA button — the actual centerpiece of the whole Message/Bubble/Attachment family. This is the institution's formatted announcement, not a conversational reply (that's Bubble).
Chrome: none by defaultA plain block — no bubble shape, no border, no fill — matching the real live Message Center app exactly. The staff-mobile mockups show a white-bubble chrome for the same content; that's documented below as an optional card variant, not the default. The live product is the source of truth here.
Not sender-basedConfirmed against the real screenshots: even a staff member's own short reply renders as a Bubble, not a Message. This component is for genuinely formatted/designed content, regardless of who's sending it.
Reuses, doesn't rebuildSender avatar is a real Avatar (resolved from avatar.tokens.json). The CTA is a real Button primary (resolved from button.tokens.json). A body Attachment is a real, unmodified Attachment (resolved from attachment.tokens.json) — same one Bubble nests too. Message only owns the layout rhythm and body typography around them.
One bold, two jobsA subheading and an inline run-in label are the same treatment (weight.semibold on body-base) applied to a standalone paragraph vs. a leading <strong> — not two typography tokens.

Sender row

Alexander Robinson -- Dec 19, 2:54 PM

<div class="message"><div class="message__sender">
      <span class="avatar"><span class="avatar__initials">AR</span></span>
      <p class="message__sender-line"><span class="message__name">Alexander Robinson</span><span class="message__meta"> -- Dec 19, 2:54 PM</span></p>
    </div></div>

Avatar (its own component, resolved not retyped — SM size, 32px) + one line: name (semibold, text.secondary) + " -- " + timestamp (muted). Rebalanced 2026-07-24: smaller avatar + gray name so the sender line stops competing with the body.

Paragraph + inline emphasis

This compacted term allows you to earn up to 4 units in just a few weeks.

<div class="message__body"><p>This compacted term allows you to earn up to <strong>4 units</strong> in just a few weeks.</p></div>

text-style.body-base, verbatim. is just weight.semibold — no second typography token.

Subheading (same treatment, standalone)

Important Details

Dates: December 19, 2025 – January 12, 2026

<div class="message__body"><p><strong>Important Details</strong></p><p><strong>Dates:</strong> December 19, 2025 – January 12, 2026</p></div>

The exact same bold-emphasis idea used two ways: a standalone paragraph reads as a subheading, a leading reads as a run-in label. One token, two usages.
