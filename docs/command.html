Command

tokens/components/command.tokens.json · generated — a search over actions: type, and the list narrows to the things you can do or the places you can go; Enter runs one. Inline, or as the command palette on Ctrl/⌘+K.

vs ListboxListbox picks a value that stays selected (a check mark). A Command item has no selected state — it runs: goes somewhere, does something. To pick a value with search, use a Listbox with its search header.
Field48px row, search icon (icon.muted), a borderless input in Search's value type — 16px, so iOS doesn't zoom — and a hairline under it.
RowsListbox's option recipe at a declared 36px: icon (icon.secondary), label, an optional shortcut (body-sm, text.muted). The active row — keyboard or pointer — gets the fill.neutralHover wash. Groups have a 12px semibold heading and a hairline between them; a group with no matches hides.
KeyboardType to filter (labels and keywords), ↑ ↓ / Home / End to move, Enter to run, Escape closes the palette.
Radiusradius.default (8px) inline and in the dialog — concentric with the rows: 4px row radius + 4px list padding = 8. Modal's 24px corner around 4px rows looked square and cramped.
DialogModal's shadow.lg and surface.overlay, 560px wide, 15% from the top. Ctrl/⌘+K opens and closes it; picking an item closes it.
