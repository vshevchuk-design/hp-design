Student Message Center

Interactive prototype, built strictly from hp-design components (every recipe resolved from its own token file) — mobile-first, responsive. Click a thread, switch Inbox/Archived, search, sort, send a reply, archive a thread — all real. New message is a full-screen bottom sheet on mobile and a centered modal on tablet/desktop; the chosen department's settings decide who the student can write to (department only / members only / both, with per-member availability), and Send starts a real Inbox thread with an Awaiting reply badge. Staff-side features (flags, Handled by, filters) are deliberately absent: this is the student app.
