Student Message Center

Interactive prototype, built strictly from hp-design components (every recipe resolved from its own token file) — mobile-first, responsive. Click a thread, switch Inbox/Archived, search, sort, send a reply, archive a thread — all real. Staff-side features (flags, Handled by, filters) are deliberately absent: this is the student app.
