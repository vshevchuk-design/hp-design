Select

tokens/components/select.tokens.json · generated — the field that shows a choice and opens a Listbox under it. Every preview is the real one from tools/lib/select.mjs: click, pick, use the keyboard.

Select + ListboxTwo components, like Radix's Select.Trigger + Select.Content: Select is the field, Listbox the panel. The same Listbox serves Combobox, MultiSelect and filters.
Box modelInput's: sm 32px / base 40px / lg 48px, surface.dim fill, floating label on base/lg.
Focus vs openFocus — the field is active but closed (you Tabbed onto it): border.focus. Open — the list is showing: the same border, the label turns blue and the chevron turns up. Fields show focus on click too; the keyboard-only ring (focus-visible) is for buttons and checks.
ErrorNot "typed something wrong" — a choice can still be wrong: required and nothing chosen on Submit, or a choice that stopped working (the section filled up, the advisor isn't free that day). border.dangerStrong + the Field message.
MultipleThe first choice + a Counter ("Email +2") — the field keeps one line whatever you pick. Every choice as removable chips is a different field (MultiSelectBadges).
Searchablesearchable: true puts a search box at the top of the list — Storybook's ComboboxField (and SimpleCombobox, the same without a Field). Same Select, same field, Single or Multi. Use it past ~10 options, or when people know the name they want (courses, programs, people).
Infinitesource: "fnName" — options come from the server a page at a time: window[fnName](query, offset) returns { items, hasMore }. Storybook's InfiniteComboboxField. The list's last row says what's happening: Loading… (and loads the next page when you reach it), No results, or Couldn't load + Retry. Search goes to the server.
Chipschips: true — every choice as a removable Chip in the field (Storybook's MultiSelectBadges). Use it when people need to see all of what they picked (a handful); for many, the first + Counter keeps the form tidy. The label moves above (Field) — chips leave no room to float one.
Keyboard↓ / ↑ / Enter / Space open; ↑ ↓ Home End move; Enter or Space pick; Escape closes back to the field; Tab closes. Single-select closes on pick.
