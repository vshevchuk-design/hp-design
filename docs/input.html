Input

tokens/components/input.tokens.json · generated — every preview is the real field from tools/lib/field.mjs, the one Form uses: hover it, click it, type.

Fill + bordersurface.dim fill + border.default hairline at rest — a recessed place to type.
Sizessm 32px (no floating label) / base 40px (default) / lg 48px. Value text is 16px at every size — Safari on iOS zooms the page on focus if it's smaller.
Floating labelbase/lg. Resting: the placeholder shows the label's text; the <label> is kept for screen readers. Focused or populated: a 12px label above the 16px value. Pure CSS — :focus-within / :placeholder-shown.
Stateshover border.strong · focus border.focus + blue label · disabled surface.disabled, faded · read-only white, full contrast, no hover · error border.dangerStrong (red.600 — the pale border.danger is Alert's).
Disabled vs read-onlyDisabled = unavailable right now; faded, skipped by Tab, not submitted. Read-only = this value doesn't change here, but read it, select it, copy it; submitted. If nothing on the page is editable, show text (label + value), not fields.
Typesemail / tel / url / search are type + autocomplete on this field, not variants. Password adds a reveal button. Numbers: a code or ID is inputmode="numeric"; a quantity with steps is NumberField — never type="number".
Not an InputFile upload — the native "Choose file / No file chosen" can't be styled and shows no list or progress. It's its own component (a button or drop zone + Attachment rows), on the backlog.

NumberField

A quantity with steps — credits, guests, hours. The same field + − / + at the trailing edge (Button ghost sm icon-only, out of the Tab order: the arrow keys do the same) and an optional unit: textFieldHtml({ …, number: { min, max, step, decimals, unit } }). The input is type="text" inputmode="numeric|decimal" role="spinbutton" with aria-valuemin / max / now — never type="number". Typing keeps only what can be a number; on blur the value snaps to the step and the range. A code or ID that happens to be digits is not a NumberField (nothing to step) — that's inputmode="numeric" on a plain field.
