Sidebar

tokens/components/sidebar.tokens.json · generated — the CX app's primary navigation: a brand-blue panel with flat links, collapsible groups, counts, and the signed-in person at the foot. One recipe, three shapes: expanded (288px), the collapsed rail (64px), the rail automatically between 768 and 1279px, and below 768px an off-canvas drawer. Shared with the CX prototypes through tools/lib/sidebar.mjs.

From the live appSame structure, item for item (read off a saved copy of the live Dashboard). What changed: an open group no longer becomes a white panel with dark text and a black outline — its links stay on the blue, indented under the parent's label; only the current page is a white pill. Hover is one surface step (surface.brandHover), not a darker band.
ThemesBrand blue (default) and neutral gray (.sidebar--neutral, below). Same sizes, states and behaviour; only the colour roles change.
SurfaceNew semantic roles, added for this: surface.brand (blue.700), surface.brandHover (blue.600), text.onBrandMuted (blue.100) for nested links and chevrons, border.onBrand for the dividers. Text and icons are text.onFill / icon.onFill.
Current pagearia-current="page" → white pill (surface.default), brand text and icon, semibold. A closed group that holds the current page keeps a semibold label so you can find your way back.
GroupsA button with aria-expanded + aria-controls; the list is hidden when closed. Nested links are indented 44px — their text starts under the parent's label.
CountsCounter sm in its onPrimary active colours (white chip, brand text). The inactive onPrimary chip is blue.700 — the panel's own colour — so it would vanish. In the rail a count becomes a dot.
Focusborder.focus is blue.600, invisible on this panel — the ring here is white, 2px, inset.
RailThe collapse button (top right) shrinks the panel to its icons; each item's label is its native title. Opening a group from the rail expands the panel first.
768–1279pxIn an app (.has-sidebar) the panel folds to the rail by itself, as the live app does. Expanding it (the button, or a group) opens a 320px panel over the page with a close button and a scrim — the content keeps the rail's 64px and doesn't move. ✕, the scrim, Escape or choosing a link closes it back to the rail.
Below 768pxOff-canvas; the topbar's menu button opens it full screen with a close button in the header. See it in the CX prototypes.

  --tok-avatar-blue-text: #0468c4;

/* ============ Sidebar (brand-blue primary navigation) ============ */
.sidebar { flex-shrink: 0; width: 288px; height: 100dvh; position: sticky; top: 0; display: flex; flex-direction: column; background: var(--tok-surface-brand); color: var(--tok-text-on-fill); font-family: var(--tok-family-sans); transition: width 0.2s ease; }
.sidebar__head { flex-shrink: 0; height: 64px; display: flex; align-items: center; justify-content: space-between; gap: 8px; padding: 0 12px 0 calc(12px + 12px); border-bottom: 1px solid var(--tok-border-on-brand); }
.sidebar__logo { display: flex; color: var(--tok-text-on-fill); }
.sidebar__logo svg { display: block; height: 24px; width: auto; }
/* the logo's three parts, painted per theme: on blue it inverts (white
   square, brand glyph, white wordmark); on gray it's the normal logo */
.sidebar__logo-mark { fill: var(--tok-text-on-fill); }
.sidebar__logo-glyph { fill: var(--tok-surface-brand); }
.sidebar__logo-word { fill: var(--tok-text-on-fill); }
/* the 24px square mark alone, for the rail */
.sidebar__mark { display: none; }
.sidebar__list, .sidebar__sub { list-style: none; margin: 0; padding: 0; display: flex; flex-direction: column; gap: 4px; }
.sidebar__body { flex: 1; min-height: 0; overflow-y: auto; padding: 12px; scrollbar-width: thin; scrollbar-color: var(--tok-surface-brand-hover) transparent; }
.sidebar__sub { margin-top: 4px; }
.sidebar__sub[hidden] { display: none; }
/* one row recipe for links, group headers, the account button and the
   collapse button */
.sidebar__item { width: 100%; height: 40px; display: flex; align-items: center; gap: 12px; padding: 0 12px; border: none; border-radius: 8px; background: transparent; color: var(--tok-text-on-fill); text-decoration: none; text-align: left; cursor: pointer; font-family: inherit; font-weight: 400; font-size: 14px; line-height: 1.4; }
.sidebar__icon { flex-shrink: 0; width: 20px; height: 20px; color: var(--tok-icon-on-fill); }
.sidebar__label { flex: 1; min-width: 0; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
.sidebar__chevron { flex-shrink: 0; width: 20px; height: 20px; color: var(--tok-text-on-brand-muted); transition: transform 0.15s ease; }
.sidebar__item[aria-expanded="true"] .sidebar__chevron { transform: rotate(180deg); }
.sidebar__item--child { padding-left: 44px; color: var(--tok-text-on-brand-muted); }
.sidebar__item:hover { background: var(--tok-surface-brand-hover); color: var(--tok-text-on-fill); }
.sidebar__item:focus-visible { outline: 2px solid var(--tok-text-on-fill); outline-offset: -2px; }
/* the current page — the one loud thing in the panel */
.sidebar__item[aria-current="page"] { background: var(--tok-surface-default); color: var(--tok-text-primary); font-weight: 600; font-size: 14px; line-height: 1.4; }
.sidebar__item[aria-current="page"] .sidebar__icon { color: var(--tok-icon-primary); }
.sidebar__item[aria-current="page"]:focus-visible { outline-color: var(--tok-icon-primary); }
/* a group holding the current page reads semibold even while closed */
.sidebar__item.has-current { font-weight: 600; font-size: 14px; line-height: 1.4; }
/* group count: Counter sm, onPrimary ACTIVE colours (inactive = the panel's own blue) */
.sidebar__count { flex-shrink: 0; display: inline-flex; align-items: center; justify-content: center; height: 16px; min-width: 16px; padding: 0 4px; border-radius: 999px; background: var(--tok-surface-default); color: var(--tok-text-primary); font-weight: 700; font-size: 10px; line-height: 1; }
/* an open group keeps its total, but quiet — the loud count belongs to the
   child that actually has the items. (The rail keeps the loud dot: the
   children aren't visible there.) Blue: one surface step up, white label —
   the inactive onPrimary chip is the panel's own blue and would vanish. */
.sidebar:not(.sidebar--collapsed) .sidebar__item[aria-expanded="true"] > .sidebar__count { background: var(--tok-surface-brand-hover); color: var(--tok-text-on-fill); }
/* the footer band matches the header: 64px declared, hairline inside it */
.sidebar__foot { flex-shrink: 0; height: 64px; display: flex; align-items: center; padding: 0 12px; border-top: 1px solid var(--tok-border-on-brand); }
.sidebar__account { height: 40px; }
.sidebar__avatar { flex-shrink: 0; width: 32px; height: 32px; margin-left: -4px; border-radius: 50%; display: inline-flex; align-items: center; justify-content: center; background: var(--tok-avatar-blue-bg); color: var(--tok-avatar-blue-text); font-weight: 600; font-size: 12px; line-height: 1; }
.sidebar__collapse { width: 40px; padding: 0; justify-content: center; flex-shrink: 0; }
.sidebar__collapse .sidebar__icon { transition: transform 0.2s ease; }

/* ---- neutral theme: the same recipe on gray ---- */
.sidebar--neutral { background: var(--tok-surface-dim); color: var(--tok-text-default); scrollbar-color: var(--tok-fill-neutral-hover) transparent; box-shadow: inset -1px 0 0 var(--tok-border-default); }
.sidebar--neutral .sidebar__head { border-bottom-color: var(--tok-border-default); }
.sidebar--neutral .sidebar__foot { border-top-color: var(--tok-border-default); }
.sidebar--neutral .sidebar__body { scrollbar-color: var(--tok-fill-neutral-hover) transparent; }
.sidebar--neutral .sidebar__logo { color: var(--tok-text-default); }
.sidebar--neutral .sidebar__logo-mark { fill: var(--tok-text-primary); }
.sidebar--neutral .sidebar__logo-glyph { fill: var(--tok-text-on-fill); }
.sidebar--neutral .sidebar__logo-word { fill: var(--tok-text-default); }
.sidebar--neutral .sidebar__item { color: var(--tok-text-default); }
.sidebar--neutral .sidebar__icon { color: var(--tok-icon-secondary); }
.sidebar--neutral .sidebar__item--child { color: var(--tok-text-secondary); }
.sidebar--neutral .sidebar__chevron { color: var(--tok-icon-muted); }
.sidebar--neutral .sidebar__item:hover { background: var(--tok-fill-neutral-hover); color: var(--tok-text-default); }
.sidebar--neutral .sidebar__item:focus-visible { outline: 2px solid var(--tok-border-focus); outline-offset: -2px; }
.sidebar--neutral .sidebar__item[aria-current="page"] { background: var(--tok-surface-default); color: var(--tok-text-primary); }
.sidebar--neutral .sidebar__item[aria-current="page"] .sidebar__icon { color: var(--tok-icon-primary); }
.sidebar--neutral .sidebar__count { background: var(--tok-fill-primary); color: var(--tok-text-on-fill); }
/* gray: Counter onNeutral INACTIVE for an open group's total */
.sidebar--neutral:not(.sidebar--collapsed) .sidebar__item[aria-expanded="true"] > .sidebar__count { background: var(--tok-fill-neutral-active-strong); color: var(--tok-text-default); }

/* ---- collapsed rail: icons only (desktop; below 1024 the panel is a drawer) ---- */
@media (min-width: 768px) {
  .sidebar--collapsed { width: 64px; }
  .sidebar--collapsed .sidebar__head { flex-direction: column; justify-content: center; padding: 0; }
  .sidebar--collapsed .sidebar__logo { display: none; }
  .sidebar--collapsed .sidebar__collapse .sidebar__icon { transform: rotate(180deg); }
  .sidebar--collapsed .sidebar__label, .sidebar--collapsed .sidebar__chevron, .sidebar--collapsed .sidebar__sub { display: none; }
  .sidebar--collapsed .sidebar__item { justify-content: center; padding: 0; }
  .sidebar--collapsed .sidebar__avatar { margin-left: 0; }
  /* the count shrinks to a dot on the icon's corner */
  .sidebar--collapsed .sidebar__item { position: relative; }
  .sidebar--collapsed .sidebar__count { position: absolute; top: 4px; right: 4px; min-width: 0; width: 8px; height: 8px; padding: 0; font-size: 0; }
}

/* ---- the panel opened over the page (tablet overlay, phone full screen) ---- */
/* its close button replaces the collapse button while it's open */
.sidebar__close { display: none; }
.sidebar-scrim { display: none; }
@media (max-width: 1023px) {
  .has-nav-open .sidebar__close { display: inline-flex; width: 40px; padding: 0; justify-content: center; flex-shrink: 0; }
  .has-nav-open .sidebar__collapse { display: none; }
  .has-nav-open .sidebar-scrim { display: block; position: fixed; inset: 0; z-index: 19; background: var(--tok-surface-overlay); }
}
/* tablet (768–1023): the rail stays in the page; opening it lays a 320px
   panel over the content — the content keeps the rail's 64px, so nothing
   underneath moves. (1024–1279 is a desktop: the rail expands in place.) */
@media (min-width: 768px) and (max-width: 1023px) {
  .has-nav-open .sidebar { position: fixed; left: 0; top: 0; bottom: 0; z-index: 20; height: auto; width: 320px; box-shadow: 0 0 0 1px var(--tok-border-on-brand); }
  .has-nav-open > .sidebar-scrim + * { margin-left: 64px; }
}
/* phone (< 768): off-canvas, opened full screen by the topbar's menu button */
@media (max-width: 767px) {
  .sidebar, .sidebar.sidebar--collapsed { position: fixed; left: 0; top: 0; bottom: auto; z-index: 20; width: 100vw; height: 100lvh; transform: translateX(-100%); transition: transform 0.25s ease; }
  /* full LARGE-viewport height (under iOS Safari's floating bottom bar), the
     account row lifted above the bar and the home indicator */
  .sidebar__foot { height: calc(64px + env(safe-area-inset-bottom) + 100lvh - 100dvh); padding-bottom: calc(env(safe-area-inset-bottom) + 100lvh - 100dvh); }
  .sidebar__collapse { display: none; }
  .has-nav-open .sidebar { transform: none; }
}
@media (prefers-reduced-motion: reduce) { .sidebar, .sidebar__chevron, .sidebar__collapse .sidebar__icon { transition: none; } }
