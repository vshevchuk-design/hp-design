Attachment

tokens/components/attachment.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, nothing hand-copied. Colors are CSS custom properties, not literal hex.

Two contextsComposer, pre-send (idle/uploading — a real remove/cancel <button>) and message display, post-send (done — the whole row becomes a real <a download>, not a div with a nested button).
icon vs. image mediaicon: insert_drive_file.svg in a raised surface.default square inside the card's own surface.sunken — the "icon in a soft square" pattern noted years ago, first real use of it. image: a real <img> thumbnail filling the same box.
One sizeAn attachment row doesn't need an sm/base/lg ladder — same reasoning as Card/Menu/Popover.
No error stateNot seen as a real need in the driving screenshots — only idle/uploading/done exist. Revisit if a real failed-upload case appears.
Remove buttonResolved from Popover/Drawer/Modal's own close-button recipe, not re-invented: transparent → fill.neutralHover → fill.neutralActive.
