Calendar

tokens/components/calendar.tokens.json · generated — the bare month grid every date component is built on. No trigger, no surface: DatePicker puts it in a popover, DateRangePicker puts two months of it in a popover with Reset / Apply, a page can drop it into a Card.

HeaderPaging arrows (32px, icon.default) around a month + year select pair — 32px controls in the field family on surface.default, so a date two years out is two picks. With two months the arrows sit on the outer edges only.
Grid7 × 36px days = a 252px month. Weekdays in label-sm / text.muted. Columns sit flush so a range reads as one band; weeks are 2px apart.
DaysToday gets a hairline border.strong ring. Selected (single) and start / end (range) fill fill.primary; the days between get a bg.primary wash. Days from the neighbouring months are muted and not pickable; days outside min / max are text.disabled and not pickable either.
KeyboardOne day is in the tab order. Arrows move by a day / week, Home / End to the week's start / end, PageUp / PageDown by a month (with Shift — a year); Enter or Space picks.

Single date

"Today" is pinned to Oct 21, 2026 on this page so it renders the same every day.

Selected

Today is selected — the fill wins over the ring.

Nothing selected

Only today's ring until a day is picked.

With min date

min = today: earlier days are disabled, and the prev arrow is disabled because the month before is entirely in the past.

Range

First click sets the start, the second sets the end; clicking a day before the start swaps them. A third click starts a new range.

Two months

The DateRangePicker panel. The months page together; each one's selects move only it (the other follows to stay consecutive). Under 560px they stack.

One month

For narrow containers — the filters drawer on a phone.

Markup

The server renders the headers and empty grids; hpCalendar.mount() fills the days from the data-* attributes and keeps them in sync. Dates are ISO YYYY-MM-DD.

<div class="calendar" role="group" aria-label="Start date"
     data-mode="single" data-value="2026-10-21" data-today="2026-10-21" data-min="2026-10-21">
  <div class="calendar__months">
    <div class="calendar__month">
      <div class="calendar__head">
        <button class="calendar__nav calendar__nav--prev" aria-label="Previous month">…chevron_left…</button>
        <span class="calendar__selects">
          <span class="calendar__sel"><select class="calendar__select calendar__select--month" aria-label="Month">…</select>…expand_more…</span>
          <span class="calendar__sel"><select class="calendar__select calendar__select--year" aria-label="Year">…</select>…expand_more…</span>
        </span>
        <button class="calendar__nav calendar__nav--next" aria-label="Next month">…chevron_right…</button>
      </div>
      <div class="calendar__grid" role="group"><!-- weekdays + days, rendered by hpCalendar --></div>
    </div>
    <!-- data-mode="range" + a second .calendar__month: prev on the first head, next on the last,
         .calendar__nav-sp spacers on the inner sides -->
  </div>
</div>

<script>
  const cal = hpCalendar.mount(el, { onChange: (value) => { /* single: {y,m,d} · range: {start, end} */ } });
  cal.setValue(…); cal.setView({ y: 2026, m: 9 }); cal.focus();
</script>
