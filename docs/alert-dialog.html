AlertDialog

tokens/components/alert-dialog.tokens.json · generated — a confirmation the user has to answer. Same shell as Modal; no close (×), no click-outside, no Escape — only the actions close it.

ShellModal's, resolved from modal.tokens.json: 384px wide, radius.xl, shadow.lg, surface.default over a surface.overlay backdrop, 24px padding, native showModal().
LayoutOne block — title (heading-lg) over description (body-base, text.secondary) 8px apart, actions 24px below, right-aligned, safe action first. No header / footer bands, no dividers.
Can't be dismissedNo ×. A backdrop click does nothing (there's no outside-click handler), and Escape is blocked by preventDefault() on the dialog's native cancel event.
A11yrole="alertdialog", aria-labelledby the title, aria-describedby the description. autofocus on Cancel, so Enter right after opening never confirms a destructive action.
WhenIrreversible or destructive confirmations only. Anything that can be undone, or that the user can safely walk away from, is a plain Modal.

Examples

Open one, then try Escape or clicking the backdrop — it stays.

Destructive

Delete your account?

This is permanent — your account, messages and history are deleted immediately. There's no undo.

The destructive action in fill.danger, Cancel first and focused.

Discard changes

Discard unsaved changes?

You've edited this message. If you leave now, your changes are lost.

Cancel can be renamed to say what staying means.

Confirm (not destructive)

Submit your application?

Once it's sent you can't edit it. We'll email you as soon as an advisor has reviewed it.

Significant but not destructive — the action in fill.primary. Figma: Tone=Default.

Markup

<button data-alert-dialog-open="delete-account">Delete account</button>

<dialog class="alert-dialog" id="delete-account" role="alertdialog"
        aria-labelledby="delete-account-title" aria-describedby="delete-account-desc">
  <div class="alert-dialog__content">
    <div class="alert-dialog__text">
      <h2 class="alert-dialog__title" id="delete-account-title">Delete your account?</h2>
      <p class="alert-dialog__description" id="delete-account-desc">This is permanent…</p>
    </div>
    <!-- method="dialog": either button closes it; dialog.returnValue = "cancel" | "confirm" -->
    <form class="alert-dialog__actions" method="dialog">
      <button value="cancel" autofocus>Cancel</button>
      <button value="confirm">Delete my account</button>
    </form>
  </div>
</dialog>

Script

Open, and block Escape. There is deliberately no click-outside handler.

document.querySelectorAll('[data-alert-dialog-open]').forEach((btn) => {
  btn.addEventListener('click', () => document.getElementById(btn.dataset.alertDialogOpen).showModal());
});
document.querySelectorAll('dialog.alert-dialog').forEach((dlg) => {
  dlg.addEventListener('cancel', (e) => e.preventDefault());
});
