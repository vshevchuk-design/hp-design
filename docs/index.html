hp-design

Design system for Highpoint products. The source of truth for tokens and components — everything else (prototypes, products) is built strictly on top of them.

Colors

10 ramps

OKLCH primitive ramps (25→950) + a validated categorical palette for charts.

Semantic colors

7 groups

surface · bg · border · text · icon · fill · status — built on top of primitives.

Typography

Sora

Family, weight, size, leading, tracking + 17 text-styles.

Layout

dim · radius · z

Spacing scale, radius scale, z-index tiers.

Icons

136

Material Icons, Filled style, SVG — currentColor, extended as real need appears.

Button

Primary · Secondary · Ghost

sm/base/lg · 5 content variants · 5 states.

Counter

onPrimary · onNeutral

Numeric badge sitting inside a button. Inactive/active.

Input

sm · base · lg

Floating label at base/lg, 16px value text (Safari-safe), 6 states.

Select

sm · base · lg

Same grid as Input, + an always-visible chevron.

Search

sm · base · lg

No floating label, leading search icon, clear (×) shown once there's a value.

Pagination

1 size

First/last page always visible, no jump-to-first/last arrows.

Separator

no states

Horizontal/vertical + a with-label variant, centered.

Tabs

segmented · underline

sm · base, counter reuses onNeutral, no hard cap on tab count.

Checkbox

1 size

Native input, check/indeterminate from Material icons, vertical/horizontal groups.

Radio

1 size

Native input, ring + dot (no icon), vertical/horizontal groups.

Box

no states

The lowest layout primitive — surface/border/padding directly, the full radius scale.

Card

border, no shadow

surface.default + border.default + radius.default, optional interactive variant.

Switch

1 size

Native input, track always filled, thumb animates via transform.

Grid

gap: 0/8/12/16/24

Only gap is tokenized (same scale as Box's padding), + auto-fit with no breakpoints.

Tooltip

pure CSS

First consumer of shadow.sm and surface.inverse — :hover/:focus-within, no JS.

Popover

native popover API

Real popovertarget — top-layer, outside-click/Escape free out of the box.

Drawer

native <dialog>

showModal(), focus-trap/Escape/backdrop native, animated via @starting-style.

Modal

native <dialog>

Centered — showModal() centers for free, radius.xl, shadow.lg, + AlertDialog variant.

Menu

built on Popover

Action list (not Listbox) — text/icon variants, divider, destructive item.

Listbox

built on Popover

Options with selection state — single (checkmark) and multi-select (real Checkbox), search + select-all.

Avatar

sm · base · lg

Photo → initials → icon. Initials color is deterministic (hash of the name), 8 hues.

Badge

sm · base · lg

Status/tag pill — 5 semantic roles + 10 decorative colors, tint/solid fill.

Chip

sm · base · lg

Interactive pill — toggle (filter) and removable (dismissible tag) kinds.

Attachment

idle · uploading · done

File/image row — composer remove button, message-display real download link.

Message

chrome: none by default

Rich institution-authored content block — headings, links, images, CTA. No bubble shape.

Bubble

self · other

Plain conversational reply — text ± one Attachment. self defaults to tint, not solid.

ThreadListItem

built on Card

Left-rail row — subject, metadata, Badge value, selected state (persistent pressed).

Composer

simple · rich

Reply input — simple (student) vs. rich (staff, B/I/U + AI Assist + Switch). Family's last piece.

EmptyState

text-only

Fills an area whose content is absent — one centered hint on a long, weak gray pill.

Toast

success · danger · warning

Transient top-center feedback — popover="manual", auto-dismiss, status.* icon colors.
